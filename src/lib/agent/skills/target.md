# Target listing skill

Target scores content quality and follows category-specific formatting.

## Fields and limits
- title: up to 150 characters, aim for 21 to 100. Brand, product, size.
- bullets: 3 to 10, each up to 120 characters. Plain text with no HTML.
- description: plain text, clear and benefit-led, 80 to 200 words.

## Rules
- No promotional language, prices or shipping offers.
- No competitor references.
- No drug or medical claims.
- Write in a warm, plain voice for a shopper browsing, not a specification sheet.
