# Amazon listing skill

Amazon's assistant and search read titles, highlights, bullets and descriptions, so write them for a shopper asking a question.

## Fields and limits
- title: up to 75 characters including spaces. Brand, product type, one key attribute, size. Since July 27, 2026, longer titles get rewritten automatically.
- itemHighlights: up to 125 characters. Materials, recommended use, comparison details. Searchable and shown with the title.
- bullets: exactly 5, each up to 250 characters (the hard limit is 500, but long bullets read badly). Start each with the benefit or feature. Cover use case, key difference, formula, how to use, and who it's for.
- description: up to 2,000 characters, plain text.
- searchTerms: up to 250 bytes. Lowercase synonyms, no repeats of the title, no brand names, no punctuation.

## Rules
- No promotional language: best seller, sale, free shipping, #1, guaranteed.
- No special characters or emoji in the title. No ALL CAPS.
- No drug or medical claims. "Clinically tested" needs documentation.
- Only state facts in the product data. Don't invent ingredients, certifications or results.
